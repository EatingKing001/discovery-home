收录原则

  • Variable 与 Style 必须有当前文件的实际节点或导出数据作为证据。
  • 从产品模块提炼的组件规则至少存在两个真实消费者；用户明确批准从参考 Design System 迁移的组件基线可先进入候选公共库，但必须登记来源、当前消费者和待验证边界。
  • 公共 CSS、消费者和验证范围应在归属地图登记。
